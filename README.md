# 🚗 Vertoride – Vehicle Rental Website

**Your Ride, Your Way.**

Vertoride is a modern vehicle rental website designed to make exploring and renting vehicles simple and convenient.

## 🌟 About the Project

Vertoride aims to provide users with a simple platform to explore available vehicles and find suitable rental options according to their needs.

## ✨ Features

- Modern and clean user interface
- Responsive website design
- Vehicle browsing interface
- Easy navigation
- User-friendly experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Status

🚧 Currently under development.

## 🎯 Project Goal

To build a simple, attractive, and user-friendly vehicle rental platform while improving frontend development skills.
